# Changelog

All notable changes to **MayaMystic Logger** are documented in this file.

This project follows a structured changelog format to track improvements and new features across releases.

---

## [1.0.0] - 2026-05-25

### ✨ Added
- Initial modular Logger framework architecture
- Centralized `LoggerService`
- Structured logging system
- Configurable log levels
  - Info
  - Warning
  - Error
  - Debug
  - Exception
  - Verbose
- Log category system
- Console log writer
- Configurable logging format utilities
- ScriptableObject-based logger configuration system
- Runtime logger settings loader
- Timestamp support
- Category-based logging support
- Stack trace logging support
- `LoggerConstants`
- `LoggerCategories`
- `LoggerPaths`
- `LogFormatUtility`
- `LogFileUtility`
- `ConsoleLogWriter`
- Extensible writer architecture
- ContextMenu-based runtime testing examples

### 🚀 Improved
- Structured runtime logging workflow
- Cleaner debugging architecture
- Reusable logging pipeline
- Improved runtime debugging readability
- Better framework scalability for future logging integrations

### 🐛 Fixed
- Fixed duplicate console log formatting issues
- Fixed inconsistent category naming edge cases
- Fixed runtime logger initialization ordering issues
- Fixed invalid log formatting edge cases
